# Security

- Harness binds to `127.0.0.1` on a random port.
- Launch tokens are redacted from logs.
- API keys use VS Code SecretStorage.
- Runtime download requires confirmation.
- Untrusted workspaces are unsupported.

Harness can edit files and execute commands. Review permissions, plugins, MCP servers, and model providers before use.

Before publishing, add your security contact here.
